note（ブログサービス）の検索 API で、30語 × 人気順・新着順 × 10ページを集めて、分野ごとに有料記事の反応（スキ）の中央値を出しています。2026年10月20日と11月3日に、**同じスクリプト・同じ30語**で2回取りました。

全体の数字はほぼ同じなのに、分野別の中央値は順位ごと入れ替わりました。この記事は、その差と、差が出る仕組みと、2回目以降の計測に足した2つの列の話です。

## 2回の差

| | 10月20日 | 11月3日 |
|---|---|---|
| 集めた記事 | 10,126件 | 9,966件 |
| うち有料 | 1,313件（13.0%） | 1,194件（12.0%） |
| 有料記事のスキ中央値 | 2 | 5 |
| 「○部売れた」の売上中央値（価格×部数） | 37,620円 | 36,800円 |

ここまでは安定しています。分野別にすると、こうなります（有料記事のスキ中央値）。

| 分野（検索語） | 10月20日 | 11月3日 |
|---|---|---|
| note 収益化 | 56 | 61 |
| Threads | 38 | 45 |
| 自動化 | **2** | **59** |
| デザイン | **16** | **69** |
| AI活用 | **36** | **4** |
| フリーランス | **15** | **2** |

「自動化」は30分野中15位から3位へ、「AI活用」は3位から16位へ（同率は上位扱い）。

## なぜ入れ替わるのか

市場が2週間で変わったのではありません。**取っている集合が毎回別物**だからです。

```
https://note.com/api/v3/searches?context=note&q=<語>&size=20&start=<n>&sort=popular
https://note.com/api/v3/searches?context=note&q=<語>&size=20&start=<n>&sort=new
```

- `sort=new` は新着順なので、2週間たてば中身がほぼ全部入れ替わる
- `sort=popular` も上位200件の顔ぶれは日ごとに動く
- 分野ごとの**有料記事の件数が少ない**。「自動化」は11月3日の計測で、325件中25件が有料。25件の中央値は、反応の多い記事が2〜3本入れ替わるだけで跳ねる

つまり、分野別の中央値は「その日の人気順・新着順に乗っていた有料記事の中央値」であって、分野そのものの値ではありません。

## 2回目から足した2つの列

### 1. 件数 `n`

中央値の横に、必ずその分野の有料記事の件数を出すようにしました。`analyze.py` の分野表の行はこうです。

```python
tab.append((med([x['likes'] or 0 for x in p]), len(p) / len(v) * 100, med([x['price'] for x in p]), q, len(p)))
for m, rate, pr, q, n in sorted(tab, reverse=True):
    print(f'  {q:<14} スキ中央 {m:>4.0f}  n={n:>3}  有料率 {rate:5.1f}%  価格中央 {pr:>6.0f}円')
```

`n` が 30 未満の行は、記事や報告の見出しに使わない、と決めています。

### 2. 取得日

出力の先頭に取得日を入れ、2回分を並べて比べられるようにしました。要約は `summary.json` に日付をキーにして2回分を持ちます。

```json
{
  "2026-10-20": {"記事": 10126, "有料": 1313, "書き手": 846, "販売実例": 745},
  "2026-11-03": {"記事": 9966,  "有料": 1194, "書き手": 832, "販売実例": 756}
}
```

## 1回目の表で書いてしまったこと

10月20日の表をもとに、有料記事に「自動化の分野は反応が少ない（中央値2）」と書きました。11月3日は59です。10月の数字が間違っていたのではなく、**1回の計測で順位を結論にしたのが間違い**でした。有料記事には「取得日が1回分」の注記を足します。

## 持ち帰れる形にすると

指示に足すなら、この2行です。

```
分野ごとの集計には、取得日と件数（n）を必ず付けてください。
1回の計測で順位を結論にせず、間を空けてもう1回取って比べてください。
```

何を数えて、2回の差をどう読んだかは note に書いています（調べた結果は無料部分で全部読めます）。
