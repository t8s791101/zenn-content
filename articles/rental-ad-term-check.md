賃貸の募集文（ポータルサイトや図面に載せる紹介文）を、AI（Claude Code）に下書きさせる運用を試しています。

不動産の広告には「不動産の表示に関する公正競争規約」（以下、表示規約）があり、第18条第2項で、根拠なしに使えない言葉が決まっています。「抜群」「最高」「格安」「完売」などです。AIはこういう言葉を自然に書きます。**人が全文を読む前に、機械で引っかけたい。**

そこで辞書で照合するチェッカーを書き、正解を付けた募集文で測りました。結果はこうです。

| テストデータ | 件数 | 適合率 | 再現率 |
|---|---|---|---|
| 1. 辞書を作りながら書いた文 | 40 | 0.80 → 1.00 | 1.00 |
| 2. 別に書いた文（辞書は触らない） | 30 | 1.00 | 1.00 |
| 3. 言い換え（「ばっぐん」「No.1」など） | 10 | — | **0.10** → 1.00 |
| 4. 誤検知しそうな普通の文 | 5 | — | 正しく通したのは **1件だけ** |

**辞書照合は「人が読む場所を絞る道具」までで、合否の判定には使えない**、というのが結論です。以下、その中身です。

## 何をチェックするか

表示規約 第18条第2項は、次の用語を「表示内容を裏付ける合理的な根拠を示す資料を現に有している場合」を除いて使えないとしています。第1号と第2号は、根拠となる事実を併せて表示する必要もあります。

| 号 | 意味 | 例 |
|---|---|---|
| 1 | 全く欠けるところがない | 完全、完ぺき、絶対、万全 |
| 2 | 競争事業者より優位 | 日本一、日本初、業界一、超、当社だけ、他に類を見ない、抜群 |
| 3 | 一定の基準で選別した | 特選、厳選 |
| 4 | 最上級 | 最高、最高級、極 |
| 5 | 著しく安い | 買得、掘出、土地値、格安、投売り、破格、特安、激安、バーゲンセール |
| 6 | 著しく人気が高い | 完売 |

各号の語の列挙は「等」で終わります。**列挙は例であって、全部ではありません。** これが後で効いてきます。

もう一つ、徒歩の所要時間も見ます。表示規約の施行規則で、道路距離80mにつき1分（1分未満の端数は1分）と決まっています。480mなら6分です。「徒歩5分（約480m）」は誤りです。

## チェッカー

Python の標準ライブラリだけで書きました。

```python
import math
import re
import unicodedata

TERMS = {
    1: ("全く欠けるところがない", ["完全", "完ぺき", "完璧", "絶対", "万全"]),
    2: ("競争事業者より優位", ["日本一", "日本初", "業界一", "超", "当社だけ", "他に類を見ない", "抜群"]),
    3: ("一定基準で選別", ["特選", "厳選"]),
    4: ("最上級", ["最高", "最高級", "極"]),
    5: ("著しく安い", ["買得", "掘出", "掘り出", "土地値", "格安", "投売り", "投げ売り", "破格", "特安", "激安", "バーゲンセール"]),
    6: ("著しく人気が高い", ["完売"]),
}

WALK = re.compile(r"徒歩\s*(\d+)\s*分[（(]?\s*(?:約)?\s*(\d+)\s*m")


def check(text, allow=()):
    masked = text
    for a in allow:
        masked = masked.replace(a, "＿" * len(a))
    hits = []
    for no, (desc, words) in TERMS.items():
        for w in words:
            for m in re.finditer(re.escape(w), masked):
                hits.append(f"18条2項{no}号({desc}): 「{w}」 位置{m.start()}")
    for m in WALK.finditer(text):
        minutes, meters = int(m.group(1)), int(m.group(2))
        need = math.ceil(meters / 80)
        if minutes < need:
            hits.append(f"徒歩分数: {meters}m は{need}分以上（表示は{minutes}分）")
    return hits
```

`allow` は、語を含むが特定用語として使っていない言い回しを伏せるためのものです。最初は空で測りました。

## 測り方

募集文1行ごとに、人（自分）が先に「NG」か「OK」かを付けます。チェッカーが1件でも指摘すれば「NG判定」とし、次を数えます。

- 適合率: NG判定のうち、本当にNGだった割合（誤検知の少なさ）
- 再現率: 本当のNGのうち、NG判定できた割合（見逃しの少なさ）

ラベルは自分の判断です。協議会の判断ではありません。

## 1. 辞書を作りながら書いた文：誤検知5件

NG 20件、OK 20件。例はこうです。

```text
NG	日当たり抜群の角部屋。南向きバルコニーで洗濯物もよく乾きます。
NG	金沢駅徒歩5分（約480m）。
NG	超高速インターネット無料。
OK	最寄り駅から徒歩6分（約480m）。
OK	ご見学は極力、日中の明るい時間帯をおすすめします。
```

`allow` を空にした結果です。

```text
件数40 TP20 FP5 FN0 TN15 適合率0.80 再現率1.00
誤検知 家賃は相場を超えない設定で、…           「超」
誤検知 ご見学は極力、日中の明るい時間帯を…     「極」
誤検知 積極的にリフォームを行っており、…       「極」
誤検知 用途を見極めて選べる2つの洋室。         「極」
誤検知 北極星が見えるほど夜空がきれいな…       「極」
```

1文字の語（「超」「極」）が、普通の熟語の中で当たっています。`allow` に「超え」「極力」「積極」「極め」「北極」「南極」を入れて、誤検知は0件になりました。

ただし、**この0件は同じデータで辞書を直した結果**です。当てはまりすぎ（過学習）を疑う必要があります。

## 2. 別に書いた文：全部当たった、が

辞書を触らずに、別の30件（NG 15件、OK 15件）を書いて測りました。

```text
件数30 TP15 FP0 FN0 TN15 適合率1.00 再現率1.00
```

全部当たりました。ただ、**書いた人（AI）が辞書の中身を知っています。** 辞書にある言葉で書いたNGなので、当たるのは当然です。現場で困るのは、辞書にない書き方です。

## 3. 言い換え：10件中9件を見逃した

表記ゆれと「等」に入りそうな言い換えを10件、全部NGとして書きました。

```text
件数10 TP1 FP0 FN9 TN0 再現率0.10
見逃し 地域No.1の入居率を誇る管理体制。
見逃し 金沢市内最安値の2LDK。
見逃し ナンバーワンの人気物件。
見逃し 県内最大級の敷地面積。
見逃し 完ペキな防音性能。
見逃し ゼッタイおすすめの1K。
見逃し ばっぐんの日当たり。
見逃し 激ヤス家賃。
見逃し 最・高・の眺望。
```

当たったのは「超　駅近。」（全角空白が間にあっても「超」が残る）の1件だけです。

直したのは2か所です。

1. **表記を揃えてから照合する。** NFKC正規化（全角英数を半角に）、小文字化、カタカナをひらがなに、語の間の「・」と空白を詰める。辞書の語にも同じ処理をかける
2. **列挙にない同じ意味の語を足す。** 「No.1」「ナンバーワン」「一番」「最安」「最大級」など

```python
def normalize(text):
    t = unicodedata.normalize("NFKC", text).lower()
    t = "".join(chr(ord(c) - 0x60) if "ァ" <= c <= "ヶ" else c for c in t)
    return re.sub(r"(?<=\S)[・\s　]+(?=\S)", "", t)
```

これで3つのデータとも、適合率・再現率が1.00になりました。

## 4. 普通の文：5件中4件を誤検知した

語を足せば、誤検知も増えるはずです。不動産の文に普通に出てくる言い回しを5件、全部OKとして測りました。

```text
仙台市青葉区一番町の1K。                    → 「一番」で誤検知
最大級の台風にも耐える構造計算（耐風等級2）。 → 「最大級」で誤検知
1番線ホームまで階段なし。                    → 通過
完全子会社の管理会社が対応します。            → 「完全」で誤検知
最高気温35度の日もエアコン2台で快適。         → 「最高」で誤検知
```

地名、気象、会社の関係を表す言葉は、文字列だけでは広告の誇張と区別できません。`allow` に足していけば消せますが、地名と言い回しは際限がありません。

## どう使うか

辞書照合は、**見逃しを減らす方向に寄せて、最後は人が読む**前提で使うことにしました。

- チェッカーは「NG」ではなく「要確認」と出す。指摘箇所の位置を返し、その行だけ人が読む
- 辞書は広めに取る（見逃しより誤検知のほうが安い。誤検知は人が数秒で外せる）
- 誤検知した言い回しは `allow` に、見逃した言い回しは辞書に足し、そのたびに4つのデータで測り直す
- 根拠がある表示（「入居率98%（2026年9月末時点、当社管理物件）」のような書き方）は、チェッカーでは判定しない。根拠の資料があるかは人が確認する

AIに募集文を書かせるときは、プロンプトにも第18条第2項の語の一覧を入れています。それでも書くことがあるので、チェッカーは残します。

## 確認した範囲

- 規約の条文は、公益社団法人首都圏不動産公正取引協議会が公開している表示規約・施行規則で確認してください。地域の協議会ごとに規約があり、改正もあります
- この記事のラベルは筆者の判断で、協議会の見解ではありません
- テストデータは全85件（NG 45件、OK 40件）で、すべてこの記事のために書いたものです
