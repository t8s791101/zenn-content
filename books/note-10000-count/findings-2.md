## 6. 採らなかったもの

正直に書きます。売れている3本には、**私が採らないと決めたもの**が入っていました。

- 「売り切れ次第、値上げしていきます」
- 「※9/11 売り切れ再販 3980円→4980円に値上げしました」

品切れの演出と、値上げの予告です。
これが効いている可能性は否定できません。**それでも採りません。**

私は「実際に起きたことだけを書く」「盛った数字を入れない」を自分に課しています。
売れていない数字をここに書いているのも同じ理由です。**採らない分は、中身で埋めます。**

## 7. ジャンルによって、反応が38倍ちがった

同じ「有料記事」でも、分野によって反応がまったく違いました。
検索語ごとに、有料記事のスキの中央値を出しています。

| 分野 | 有料記事のスキ中央値 | 有料率 |
|---|---|---|
| note収益化 | **56** | 11.8% |
| Threads | **38** | 25.6% |
| 題名にClaude Code・AI自動化を含む（68件） | **38** | — |
| Claude | 28 | 12.0% |
| AI副業 | 10 | 16.3% |
| 復縁 | 8 | **36.7%** |
| X運用 | 8 | 19.0% |
| SNS運用 | 4 | 14.3% |
| プロンプト | 3 | 21.0% |
| 自動化 | 2 | 12.8% |
| **有料記事ぜんぶ** | **2** | 13.0% |
| 恋愛 | **1** | 20.1% |
| 生成AI | **0** | 13.0% |
| 教育 | **0** | 18.4% |

**上と下で38倍の差があります。**

意外だったのは「生成AI」と「プロンプト」です。流行っている言葉なのに、有料にすると反応がありません。
逆に「note収益化」「Threads」「Claude Code」は、有料でも読まれています。

**買う人がいる分野と、読む人しかいない分野は別です。**

もうひとつ。「有料率」が高い＝売ろうとしている人が多い、です。
「復縁」は36.7%で最高でした。**4本に1本以上が有料**です。競争は激しい。
一方「note収益化」は11.8%しかないのに、反応は最高の56。**売り手が少なくて、買い手がいる場所です。**

私は「生成AI」「自動化」のあたりで書いていました。有料記事のスキ中央値が0〜2の場所です。

## 8. 売れている人でも、累計3万円台が真ん中

期待値をはっきりさせておきます。
「○部売れた」と本人が書いている437件について、部数×価格で売上を計算しました。

| | 金額（累計） |
|---|---|
| 中央値 | **37,620円** |
| 上位25% | 66,800円 |
| 上位10% | 356,400円 |
| 20万円以上 | 66件（**15.1%**） |
| 100万円以上 | 24件（**5.5%**） |
| 最大 | 3,247万円 |

部数の中央値は**10部**、価格の中央値は**2,680円**でした。

**「売れた」と書ける人でも、真ん中は累計3万円台です。**
月に何十万という話は、上位15%より先の世界の話でした。

これは落ち込む数字ではなく、**狙いを定めるための数字**だと思っています。
いきなり月20万を狙うと、やることが決まりません。
**まず「10部×2,680円＝26,800円」を取りに行く**なら、やることははっきりします。

## 9. SNSで集客、は私の場合うまくいかなかった

「noteは外部SNSから集客しないと売れない」とよく言われます。私もそう思って、やりました。

Threadsに、**61日間で53本**投稿しました。1日も欠けていません。
Cloudflareの無料枠でプログラムを組んで、毎日21時に自動で投稿させています。

結果です。

| | 値 |
|---|---|
| 期間 | 2026年8月22日〜10月21日（61日） |
| 投稿数 | 53本 |
| 表示の合計 | **3,657回** |
| 増えたフォロワー | **1人** |
| もらったいいね | **1件** |

**3,657回表示されて、フォロワー1人です。** 0.027%。

Threads公式の集計と、自分のデータベースに記録した実測（3,506回）がほぼ一致しているので、
この数字は信用できます。

正直に言うと、これは私のやり方が悪い可能性が高いです。
Threadsで伸ばしている人は実際にいます。**ただ、「毎日投稿すれば増える」ではありませんでした。**

そして前の章で見たとおり、**フォロワー5人で740部売っている人がいます。**
集客がうまくいっていないことと、売れないことは、同じではないようです。
