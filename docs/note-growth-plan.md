## 1. 結論（優先順位）

改善は次の順でやる。上から順に「工数が小さく、効果が出るのが早く、再現性が高い」。

| # | 施策 | 工数 | 効果が出るまで | 再現性 | やること |
|---|---|---|---|---|---|
| 1 | 導線の出口を分ける | 30分 | 即日 | 高 | Zenn各記事の末尾リンクを、TOPではなく「その記事の読者が次に読む1本」に向ける |
| 2 | プロフィールを「誰の何を解決するか」に書き換える | 20分 | 1週間 | 高 | §3 のテンプレを貼る |
| 3 | 固定記事（ピン留め）を1本作る | 2時間 | 1週間 | 高 | アカウント紹介ではなく「自分解像度とは何か＋全記事の目次」 |
| 4 | タイトルと見出しの型を統一する | 記事ごと10分 | 2〜4週間 | 高 | §4 の型に沿う。検索流入は型で変わる |
| 5 | ハッシュタグを大1/中2〜3/小1で設計 | 記事ごと3分 | 2〜4週間 | 中 | §5 |
| 6 | 週次の運用フローを固定する | 初回1時間 | 1〜3ヶ月 | 高 | §6。手を動かす量ではなく「止まらないこと」が効く |
| 7 | 収益導線（メンバーシップ or 有料記事） | 1日 | 1〜3ヶ月 | 中 | §7。ただし無料記事が20本たまるまで着手しない |

**いちばん効くのは1と3。** 今は Zenn 4本（技術記事＝滞在時間が長く、読者の可処分注意が高い）から来た人が全員アカウントTOPに落ちている。TOPは「最新記事が並ぶだけの場所」で、初見の人が何のアカウントか判断できず離脱する。出口を「読む理由がある1本」に変えるだけで、同じ流入から拾える読者数が変わる。

## 2. 導線の設計（施策1・3）

### 現状

```
Zenn記事 ×4 ──（ほぼ同一の1行）──> note TOP ──?──> 離脱
Threads 自動投稿 ──> ?
自分解像度サイト ──> ?
```

### 変更後

```
Zenn記事A（launchd/Workers）──> note「AIに開発を任せた記録」まとめ記事
Zenn記事B（匿名集計）      ──> 同上（設計思想の回）
Zenn記事C（ProseMirror）   ──> note アカウント本体（自動化で運用している当事者を見せる）
Zenn記事D（OGP）           ──> note 制作記録
                                   ↓ 各記事の末尾で
                              固定記事（自分解像度とは＋目次）
                                   ↓
                              フォロー / メンバーシップ
```

### 計測方法（重要）

note は無料プランだと流入元（リファラ）が見えない。Google Analytics の設置は note pro が前提。UTMパラメータを付けても note のダッシュボードには出ない。

したがって**送り先の記事URLを分けることが、そのまま計測の代わりになる**。Zenn記事Aからしか導線を張っていない note 記事のPVは、ほぼ Zenn 記事A由来とみなせる。Zenn 側の記事別PVと突き合わせれば、記事ごとのクリック率が推定できる。

| 記録する数字 | 取得元 | 頻度 |
|---|---|---|
| Zenn 記事別PV | Zennダッシュボード | 週1 |
| note 記事別PV | noteダッシュボード | 週1 |
| 推定クリック率 = note記事PV ÷ Zenn記事PV | 手計算 | 週1 |
| フォロワー増加数 | noteプロフィール | 週1 |

閾値: 推定クリック率が **2%を下回ったら文面を変える**、5%を超えたらその文面を他記事に横展開する。

## 3. プロフィール文（コピペ可）

note のプロフィールは140字程度で切れる。「何をしている人か」より「この人をフォローすると何が手に入るか」を先に書く。

### A案（開発記録軸・現在の実態に近い）

```
現場の面倒くさいことを、AIに任せて仕組みにしています。
賃貸営業をしながら、サイト・SNS自動投稿・集計まわりを個人でつくった記録を、
うまくいった手順と事故った経緯の両方で残しています。
コードが読めなくても再現できる粒度で書きます。
自分解像度 https://jibun-kaizoudo.pages.dev
```

### B案（読者の得を前に出す）

```
「自動化したいけど何から手をつければいいか分からない」を、
実際に動いた手順まで落として書いています。
賃貸営業 × AI開発。失敗した回ほど詳しく書きます。
・つくったもの: 自分解像度（サイト / Threads自動投稿 / 匿名集計）
・技術的な詳細は Zenn: https://zenn.dev/zeroyen_dev
```

推奨は **B案**。A案は「何をしたか」の説明で終わっているのに対し、B案は冒頭1行が読者の悩みそのもので、初見の判断が速い。

### ヘッダー画像

Zenn記事で使っている OGP 生成の仕組み（ヘッドレスChrome）をそのまま流用して、1280×670 で作る。手作業でCanvaを開かないこと。既存の資産で足りる。

## 4. 記事の型

### 4-1. タイトルの型

note 内検索とGoogle検索の両方で拾われるのは、**固有名詞 + 数字 + 結果** が入ったタイトル。煽りは滞在時間で不利になる。

| 型 | 例 |
|---|---|
| 失敗 → 原因 → 対処 | 「自動投稿が8日間止まっていたのに気づかなかった理由」 |
| 期間 + 成果物 | 「9日でサイトとSNS自動投稿をつくった記録（全手順）」 |
| 判断の比較 | 「有料ツールを使わずCloudflareだけで組んだ理由と、その代償」 |
| 具体的な数字 | 「無料枠でどこまで動くか、実際の消費量を全部出す」 |
| 読者の代弁 | 「AIに任せると壊れる、が半分正しくて半分間違いだった話」 |

避ける型: 「〇〇の方法5選」「知らないと損する〜」。自分解像度の読者（実行したい人）とは合わない。

### 4-2. 本文の型

Zenn記事4本はすでに型が確立している（冒頭で結論と事故を出し、番号付きで見出しを列挙し、最後に箇条書きのまとめ）。**note でも同じ型を使う。**

```
1. 冒頭3行: 何が起きたか（数字入り）+ 何が原因だったか
2. 「この記事で書くこと」を番号で列挙（4〜7個）
3. 各セクション: 現象 → 原因 → やったこと → 結果
4. まとめ: 太字の箇条書き 5〜7行
5. 末尾1行: 次に読む記事へのリンク
```

### 4-3. 文字数

note は 3,000〜6,000字で十分。Zennの技術記事（16,000〜26,000字）をそのまま持ってこない。**note には「判断と失敗」を、Zennには「手順とコード」を置く。** 同じネタを2媒体で書き分けられるのが、この構成の最大の強み。

## 5. ハッシュタグ設計

note のハッシュタグは「大1 / 中2〜3 / 小1」の4〜5個が最適。関係ないタグを大量に付けるとスパム判定でリーチが落ちる。

| 区分 | 役割 | 候補 |
|---|---|---|
| 大（投稿数 多） | ジャンルの旗印 | `#AI` `#副業` `#プログラミング` |
| 中（投稿数 中） | 課題別の流入 | `#業務効率化` `#自動化` `#個人開発` `#Claude` |
| 小（投稿数 少） | ニッチへの確実な到達 | `#CloudflareWorkers` `#Threads自動投稿` `#賃貸営業` |

固定で付けるタグを3つ決め、記事ごとに1〜2個だけ入れ替える。毎回考え直さないこと。

## 6. 週次運用フロー（所要 合計2時間/週）

| 曜日 | 作業 | 時間 |
|---|---|---|
| 月 | 数字の記録（§2の表を埋める）。前週比だけ見る | 10分 |
| 火 | ネタ1件を決める。ネタは「先週実際に詰まったこと」から取る | 20分 |
| 水〜木 | 下書き（AIに初稿を書かせ、事実確認と数字だけ自分で入れる） | 60分 |
| 金 | 公開。ハッシュタグ、末尾リンク、見出し確認 | 20分 |
| 土日 | 何もしない | — |

週1本で年50本。**本数より、止まらないことを優先する。** 週2本にして3週で止まるより、週1本を1年続けたほうが note では確実に効く。

## 7. 収益化（着手条件つき）

**着手条件: 無料記事20本以上、フォロワー300人以上。** これを満たすまで有料化しない。母数がないまま有料化すると、数字が動かないので改善の判断材料も得られない。

| 手段 | 手数料（2026年時点・要一次確認） | 向く場面 |
|---|---|---|
| 有料記事 | 販売手数料10% + 決済手数料5〜15% | 単発の完成した手順書。300〜3,000円が中心価格帯 |
| メンバーシップ | 月額の約10〜15% | 継続的に学ぶ層向け。2025年11月時点で売上が前年同月比+81.3%と伸びている領域 |
| 定期購読マガジン | 約20% | 手数料が最も重い。今は選ばない |

推奨は **メンバーシップ（月500〜980円）**。理由は3つ。

1. 副業目標が月30万円なら、単発販売の積み上げでは作業量が青天井になる。継続課金でないと届かない
2. 自分解像度はすでに「開発が継続している」＝毎月コンテンツが自然に発生する構造がある
3. 有料記事と違い、1本ごとの出来に売上が左右されない

メンバーシップの中身は「新規記事の先行公開＋実際に動いているコードと設定ファイル」。手作業が増える特典（個別相談など）は、AIで削減できないので入れない。
